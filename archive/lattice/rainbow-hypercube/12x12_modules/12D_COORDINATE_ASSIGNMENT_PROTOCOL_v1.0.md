# 12D Coordinate Assignment Protocol v1.0

## Purpose

This document is the single authoritative source for how any artifact, node, edge, or element in the Rainbow Hypercube / Periodic Table 2.0 knowledge graph receives its 12-dimensional address.

## Core Principles

1. **The 12D coordinate is canonical.** All lower-dimensional projections (E/C/D, X/Y/Z, 12x12 matrix, etc.) are derived views.
2. **Assignment is ontological, not political.** Coordinates describe *function* across the 12 dimensions, not status or authority.
3. **Resonance is not governance.** Proximity or harmony in 12D space does not grant decision-making power.
4. **Multiple projections are encouraged.** An artifact can (and often should) have clean mappings into several different 3-axis systems.
5. **Coordinates can evolve.** As understanding of an artifact deepens, its 12D position may be refined (with clear versioning and receipts).

## The 12 Dimensions (Quick Reference)

D1  — Foundation / Energy Substrate
D2  — Information / Compute
D3  — Flow / Logistics
D4  — Form / Embodiment
D5  — Regeneration / Life Systems
D6  — Medium / Transmission
D7  — Habitat / Organized Space
D8  — Coherence / Integrity
D9  — Evolution / Learning
D10 — Governance / Law
D11 — Boundary / Security
D12 — Transcendence / Emergence

## Assignment Process

### Step 1: Dominant Function Analysis

For the artifact in question, answer:
- Which 2–4 dimensions does this thing primarily operate in or affect?
- Which dimensions are only weakly or indirectly touched?

### Step 2: Scoring (0–11 scale)

Assign an integer score 0–11 for each dimension:
- 0–2  = Almost no presence
- 3–5  = Noticeable but secondary
- 6–8  = Strong and characteristic
- 9–11 = Defining / core to the artifact's identity

### Step 3: Projection Notes

Record which 3-axis systems this coordinate maps cleanly into (e.g., "Strong GrokBrain E/C/D projection", "Maps well to Operational X/Y/Z as H12/Y12/Z12").

### Step 4: Rainbow + Polarity (Optional but Recommended)

Assign:
- A dominant Rainbow phase (or spectrum range)
- A Yin-Yang polarity description or vector

### Step 5: Documentation & Receipts

Record the reasoning and any source documents used. This creates an auditable trail.

## Versioning

When an artifact's 12D coordinate is significantly updated:
- Create a new version of the coordinate record
- Link it to the previous version
- Provide clear rationale and receipts

## Special Cases

**Living Interfaces** (e.g. the Canonical Website / Atlas Prime)
These often have high values across many dimensions. It is acceptable (and common) for them to have several dimensions in the 10–12 range.

**Pure Mechanisms** (e.g. the 12-Layer Flywheel)
These tend to have very high scores across a contiguous block of dimensions (especially D1–D4 + D12).

**Governance / Law Artifacts** (e.g. the Invariants)
Almost always have extremely high D10 and D11 scores.
