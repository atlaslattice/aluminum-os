## Purpose

Provide a reusable return packet template for GrokDream sweeps after a night of multi-model, Git, Drive, Notion, repo, or website work.

The return packet answers:

```text
What changed?
What matters?
What receipts exist?
What is missing?
What risks appeared?
What should happen next?
```
