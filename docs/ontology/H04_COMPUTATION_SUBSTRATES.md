## Purpose

Preserve the H04 Computation Substrates concept as a public-safe ontology module for Atlas Lattice.
This document classifies computation substrate families. It does not claim deployment, performance, proof, endorsement, or implementation.

## Core frame

Computation can be mapped as state transformation.
A computation substrate can be described by asking:

- where state is stored
- how state propagates
- how state changes
- how state is read
- what information lineage survives
- what evidence supports the claim

## Public-safe doctrine

```text
A neural network learns patterns.
A neuromorphic system represents event-native computation.
A reversible system emphasizes lineage preservation.
An acoustic or resonance system studies wave-mediated state change.
The lattice records what each node claims, where it came from, and what receipts support it.
```
