## Purpose

Define a maximum-use OpenAI integration sequence for Krakoa / Continuity OS / Atlas Lattice while preserving the standing boundaries:

- no premature canon
- no official OpenAI endorsement claim
- no deployment claim
- no authority leakage
- human-root remains the ratification gate

- receipts before authority
- many versions before synthesis
- INV 0: NOTHING DIES

This roadmap treats OpenAI surfaces as execution, reasoning, review, extraction, eval, and patch-preparation layers. OpenAI moves work. Governance grants authority.
